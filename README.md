The problem being solved: Transitioning a binary churn classification task into a continuous regression pipeline to predict customer salary figures.The dataset used: The standard Churn_Modelling.csv tabular dataset containing 10,000 distinct customer bank records with zero missing parameters.Features used: Ten customer profile attributes comprising age, gender, country geography, credit score, bank balance, product count, tenure, and active account status flags.Preprocessing steps: Splitting data 80/20, applying OrdinalEncoder for gender, OneHotEncoder for countries, and normalizing all metrics via a StandardScaler.Model architecture: A sequential feedforward network containing a 64-neuron hidden layer, a 32-neuron hidden layer, and a single-neuron output layer using Linear activation.Regression metrics and results: Evaluated on the test matrix showing a Mean Absolute Error of 50,419.88, an RMSE of 58,386.49, and an \(R^{2}\) score of -0.0326.How to run the project locally: Install your pip framework bundle and launch the local host terminal using the single command streamlit run app.py.How to deploy it: Push your application codebase to GitHub and connect the repository link directly onto the automated Streamlit Community Cloud hosting console.Limitations of the model: The target salary column was generated using artificially uniform values, meaning no real-world socio-economic dependencies exist for the network to decode.
